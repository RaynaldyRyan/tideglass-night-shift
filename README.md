Tideglass: Night Shift — a top-down heist stealth game. Cross the coastal archive, dodge guard vision cones and sweeping cameras, crack the Tideglass Lens case, and escape before the alarm hits 100%. Three rooms, a coin decoy, and a score breakdown on escape.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows move, E grabs the loot and the exit, click throws a decoy coin, Esc pauses.
